# CQI Action Tracking

## Purpose

**State Monitoring > CQI Action Tracking** gives monitoring users a practical
follow-up view of CQI action plans saved by facilities. It does not create a
second action plan or replace the facility CQI workflow.

## What to monitor

| Indicator | Meaning | Follow-up action |
|---|---|---|
| High-priority pending | An open action marked High priority. | Contact the facility and confirm the improvement plan. |
| Unassigned actions | An open action has no responsible person. | Ask the facility to assign an accountable owner. |
| Overdue | The target date has passed; the action is not Completed or Closed. | Escalate according to the programme's review process. |
| Due within 7 days | An open action has a target date in the next seven days. | Check progress before it becomes overdue. |

The action counts are based on the current saved CQI action-plan records. One
action may be high priority and overdue at the same time, so the indicators
must not be added together as unique action counts.

## How to use the page

1. Open **State Monitoring > CQI Action Tracking**.
2. Start with **High-Priority Pending** and **Unassigned Actions** at the top.
3. In the facility table, read the status badge and **Attention Needed** column.
4. Use search to find a facility or NIN.
5. Follow up with the facility on actions shown as overdue, due within seven days, high priority, or missing an owner.
6. Ask the facility user to update the original action plan; do not create a duplicate plan at state level.
7. After implementation, ask the facility to complete **CQI > Gap Closure** with evidence, closure remarks and revised score where applicable.

## Good action-plan record

For an achievable plan, the facility should record:

- a specific improvement action,
- one responsible person,
- priority: Low, Medium or High,
- a realistic target date,
- closure evidence and remarks when the action is complete.

This makes the tracking page useful for timely follow-up and keeps the final
assessment progress accurate.
