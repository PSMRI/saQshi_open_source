How to use State Facility Insights Map

Locate facilities, understand certification coverage, and identify latest assessment risks from Area of Concern down to subtype level.

1

Start with a view

Facility presence shows mapped facilities. Certification shows certified facilities. Use Area of Concern for assessment analysis.

2

Narrow the analysis

Choose an Area of Concern, then use the optional subtype dropdown to focus on one standard. Search can narrow results by facility, NIN, district, or block.

3

Act on the result

Hover a district for its latest score and assessed-facility count. Click clusters, zoom in, and open a facility to review details.

Read facility symbols

Shapes identify facility type. In Facility Presence and Certification views, their colour also identifies type.

DH CHC PHC AAM Other

Read Area of Concern colours

In Area of Concern view, colour means score band and the shape still means facility type. The same colour is applied to district boundaries using the latest assessed facilities in that district.

Critical: 0–25% Needs improvement: 26–60% Satisfactory: above 60%

Understand clusters

A numbered green cluster groups nearby facilities to keep the map fast and readable. Click it or zoom in to expand the individual facility symbols.

Use the latest assessment

Area and subtype scores always use each facility’s newest assessment. Districts without current assessment data remain grey, which means they need assessment coverage—not necessarily corrective action.

Practical routine: select an Area → review red districts → select a subtype to find the cause → open facility details → assign and monitor actions.
